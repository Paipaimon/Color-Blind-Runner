# Color Blind Runner - 多人协作生存游戏

## 项目概述

Color Blind Runner 是一个基于颜色可见性规则的多人在线生存游戏。每个玩家被分配不同的颜色，只能看到特定颜色的障碍物，需要通过协作和沟通来生存更长时间。

### 核心玩法

- **颜色可见性机制**：每个玩家只能看到特定颜色的障碍物
- **多人协作**：玩家需要互相提醒看不见的障碍物
- **生存挑战**：避开障碍物，尽可能生存更长距离
- **实时同步**：所有玩家状态实时同步，支持观战模式

## 技术架构

### 前端技术栈
- **TypeScript** - 类型安全的 JavaScript
- **Canvas API** - 高性能 2D 渲染

- **响应式设计** - 支持桌面端和移动端

### 后端技术栈
- **Node.js** - 服务器运行时
- **WebSocket (ws)** - WebSocket 服务器
- **TypeScript** - 服务端类型安全

## 颜色可见性规则

### 玩家颜色与可见障碍物

| 玩家颜色 | 可见障碍物颜色 |
|---------|---------------|
| 红色 (RED) | 红色、黄色、品红、白色 |
| 绿色 (GREEN) | 绿色、黄色、青色、白色 |
| 蓝色 (BLUE) | 蓝色、青色、品红、白色 |
| 黄色 (YELLOW) | 黄色、白色 |

### 障碍物颜色说明

- **基础颜色** (RED/GREEN/BLUE)：只有对应颜色玩家可见
- **混合颜色** (YELLOW/CYAN/MAGENTA)：两种基础颜色玩家可见
- **白色** (WHITE)：所有玩家都可见

## 游戏功能特性

### 多人房间系统
- 支持 2-4 人同时游戏
- 自动房间匹配或指定房间加入
- 玩家准备机制和倒计时开始

### 输入系统
- **键盘控制**：方向键或 WASD 移动
- **触控支持**：移动端触摸操作
- **输入合并**：键盘和触控输入智能合并
- **准备操作**：空格键或点击屏幕准备

### 渲染系统
- **高性能 Canvas 渲染**：60fps 流畅游戏体验
- **响应式布局**：自适应不同屏幕尺寸
- **视口管理**：智能视口缩放和居中
- **状态栏信息**：实时显示游戏统计

### 网络同步
- **服务器权威**：所有游戏逻辑在服务器执行
- **实时状态同步**：30fps 状态广播
- **个性化视图**：每个玩家接收过滤后的可见状态
- **观战模式**：死亡玩家可继续观看游戏

## 开发和部署

### 环境要求
- Node.js 18+
- TypeScript 5.0+
- 现代浏览器（支持 WebSocket 和 Canvas）

### 开发命令

```bash
# 安装依赖
npm install

# 编译 TypeScript
npm run build

# 启动服务器（生产模式）
npm run start:server

# 启动开发服务器
npm run dev:server

# 运行测试
npm test

# 监听模式测试
npm run test:watch
```

### 服务器配置

默认配置：
- **端口**：8000
- **游戏区域**：1280x720 (16:9)
- **网格**：3列 x 12行
- **刷新率**：60fps 游戏逻辑，30fps 状态同步

### 部署说明

1. **开发环境**：直接连接 Node.js 服务器 (ws://localhost:8000)
2. **生产环境**：通过反向代理支持 HTTPS (wss://)
3. **服务器参数**：可通过 URL 参数 `?server=IP地址` 指定服务器
