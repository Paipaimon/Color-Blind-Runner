# 项目规格说明（Specs）

## 项目概述
这是一个浏览器端的多人实时协作小游戏，强调信息不对称与玩家之间的语言交流。
游戏画面极简，玩法依赖判断与沟通，而非反应速度或复杂操作。

## 技术规格
- 平台：Web 浏览器
- 前端：TypeScript + HTML Canvas（原生 API）
- 后端：Node.js + WebSocket
- 不使用任何游戏引擎
- 不使用 React / Vue / Phaser 等框架
- 不使用第三方物理或渲染库

## 玩家数量
- 支持 1–4 人
- 人数可变，不同人数即为不同信息结构
- 单人模式不提供额外 UI 补偿

## 世界与运动规则
- 世界纵向滚动（由下向上）
- 所有玩家前进速度一致
- 屏幕存在三条固定路线（左 / 中 / 右）
- 玩家只能在三条路线之间切换
- 不存在后退、暂停或加速

## 玩家表现形式
- 每名玩家表现为一条从屏幕底部向上延伸的直线
- 玩家之间互相不可见
- 玩家不看到其他玩家的线或位置

## 颜色与信息规则（核心，不可更改）
- 每名玩家拥有唯一颜色
- 世界中生成带颜色的障碍物
- 玩家：
  - 看不到【自己颜色】的障碍
  - 能看到【其他颜色】的障碍
- 自己颜色的障碍在非常接近时，才会出现极弱提示
- 与自己颜色障碍发生碰撞即死亡

## 死亡与信息变化
- 玩家死亡后：
  - 该玩家不再输入
  - 该颜色的障碍依然生成
  - 其他玩家依然可见该颜色障碍
- 死亡即意味着信息源减少

## 游戏结构
- 没有关卡
- 每一局都是随机生成
- 规则固定，仅参数随机
- 游戏目标是尽可能存活更久 / 前进更远

## 设计原则
- 操作极简
- 信息不完全
- UI 不补偿信息
- 交流是核心机制，而非辅助机制

## 禁止事项
- 禁止添加剧情、角色设定
- 禁止增加技能、道具、升级系统
- 禁止引导性 UI（箭头、提示文字等）
- 禁止自动纠错或“防失败”设计
